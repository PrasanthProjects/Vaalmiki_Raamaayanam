# 🎬 వీడియో మేకర్ – వాల్మీకి రామాయణం Shorts

మీరు చేసిన క్లిప్‌లు (ఇమేజ్ / వీడియో), మీ వాయిస్, సంగీతం ఇస్తే, పూర్తి Short ఒక్క బటన్‌తో MP4 గా తయారవుతుంది (Remotion తో).
వరుస: హుక్ (క్లిప్ 1) → శ్లోకం చదువుతున్నప్పుడు క్లిప్ 2 మీద శీర్షిక + శ్లోకం → అదే చిత్రం మీద 2 సెకన్లు శీర్షిక + ప్రతిపదార్థం (వాయిస్ లేకుండా) → తాత్పర్యం (క్లిప్ 3 ఐచ్ఛికం, 4, 5) → జీవిత పాఠం (6) → ముగింపు (7).
తెరపై టెక్స్ట్: శ్లోకం, ప్రతిపదార్థం (శీర్షికతో) మాత్రమే. సబ్‌టైటిల్స్ వీడియో మీద ఉండవు – వీడియో తయారవగానే దానికి సరిపోయే SRT ఫైల్ వస్తుంది, YouTube లో అప్‌లోడ్ చేయండి.
ఇమేజ్‌లు, వీడియోలు, వాయిస్ మీరే చేయాలి (Flow, మీ గొంతు / ElevenLabs, Suno).

## ఎలా వాడాలి

1. `START_VIDEO_MAKER.bat` డబుల్-క్లిక్ చేయండి. బ్రౌజర్‌లో **http://localhost:3333** తెరుచుకుంటుంది. (నల్ల విండో తెరిచే ఉంచండి; మూసేస్తే మేకర్ ఆగిపోతుంది.)
   - claude.ai లోని సర్గ క్లిప్‌ల పేజీలో ప్రతి శ్లోకం దగ్గర **🎬 Video Maker లో ఈ శ్లోకం తెరవండి** బటన్ ఉంది – అది నేరుగా ఆ శ్లోకాన్ని తెరుస్తుంది.
2. శ్లోకం నంబర్ నొక్కండి.
3. **క్లిప్‌లు:** Flow నుండి డౌన్‌లోడ్ చేసిన ఇమేజ్ / వీడియోను సరైన బాక్స్ లోకి లాగి వదలండి (1, 2, 4, 5, 6, 7 కావాలి; 3 ఐచ్ఛికం). పేరు మార్చనక్కర్లేదు.
4. **వాయిస్:** 4 భాగాలుగా (హుక్ · శ్లోకం · తాత్పర్యం · ముగింపు) పెడితే టైమింగ్ బాగా సరిపోతుంది. ప్రతి బాక్స్‌లో ఏం చదవాలో టెక్స్ట్ ఉంది. ఒకే ఫైల్‌గా కూడా పెట్టవచ్చు.
5. **సంగీతం (ఐచ్ఛికం):** ఈ Short కి, లేదా అన్ని Shorts కి ఒకటి.
6. **👁️ Studio లో ప్లే చేసి చూడండి** – వెంటనే ప్రివ్యూ (http://localhost:3000).
7. **🎬 వీడియో తయారు చేయండి** – 2–4 నిమిషాల్లో `out/` ఫోల్డర్‌లో MP4, దానితో పాటు SRT వస్తాయి. పేజీలోనే ప్లే అవుతుంది, SRT డౌన్‌లోడ్ బటన్ కూడా ఉంటుంది.
   YouTube Studio → Subtitles → Telugu → Upload file → **With timing** లో SRT పెట్టండి.

ఫైల్‌లు `media/<కాండ>/Sarga_NNN/Sloka_NNN/` లో ఉంటాయి (git లోకి వెళ్ళవు).
