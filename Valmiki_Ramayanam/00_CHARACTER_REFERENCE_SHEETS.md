# పాత్రల రిఫరెన్స్ ఇమేజ్‌లు (Character Reference Sheets)

Google Flow లో పాత్రలు ప్రతి క్లిప్‌లో ఒకేలా కనిపించడానికి, ముందుగా ప్రతి పాత్రకు **ఒక్కసారి** ఇమేజ్ తయారు చేయండి.

1. కింది ప్రాంప్ట్‌తో Flow (లేదా ఏదైనా ఇమేజ్ టూల్) లో ఇమేజ్ తయారు చేయండి. 3–4 వెర్షన్లలో ఉత్తమమైనది ఎంచుకోండి.
2. దాన్ని `Valmiki_Ramayanam/_reference_images/` ఫోల్డర్‌లో ఇచ్చిన పేరుతో సేవ్ చేయండి (ఉదా: `RAMA_S3.png`).
3. ప్రతి క్లిప్‌లో **రిఫరెన్స్** అని ఉన్న ఇమేజ్‌లను Flow లో *Ingredients* గా జత చేసి, ఆ క్లిప్ ప్రాంప్ట్ ఇవ్వండి.
4. ఒకసారి ఆమోదించిన ఇమేజ్‌ను మార్చవద్దు. మారిస్తే ఆ పాత్ర ఉన్న అన్ని క్లిప్‌లు మళ్ళీ చేయాలి.

గుంపులు (ఋషులు, రాక్షస సైన్యం, వానర సైన్యం, దేవతలు, ప్రజలు) కు రిఫరెన్స్ అవసరం లేదు.
