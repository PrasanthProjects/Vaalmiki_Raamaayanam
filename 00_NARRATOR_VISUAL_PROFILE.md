# పురాణామృతం — NARRATOR VISUAL PROFILE
### For the rare cases where the Narrator is shown on screen (AI image / AI video)

**Default rule, unchanged:** the Narrator is voice-only and never shown — see `00_CHARACTER_BIBLE.md` → "WHO SPEAKS ON SCREEN." This file exists only for the specific, occasional cases below, where a visual for the Narrator himself is genuinely useful. **Do not start showing the Narrator routinely** — that would contradict the whole series' design (the story's characters carry every visual, not a host). Use this file only when one of the "When to use this" cases applies.

**Voice stays governed by `00_CHARACTER_BIBLE.md`.** This file is the visual companion to that Voice Profile — same person, described for image/video generation instead of TTS.

---

## When to use this

- A channel trailer / "About Puranamrutham" video where a host figure introduces the series
- A thumbnail concept that wants a storyteller figure rather than a scene still
- A "meet the narrator" or behind-the-scenes-style promotional asset
- An optional silhouette/shadow cutaway during a spoken-aside/teaching moment (the kind flagged "narrator steps outside the story" in some episode Notes columns) — **only if** the production ever decides such moments deserve a visual beat; current episodes handle these with a framing shift instead (see e.g. `E2.01` scenes 9-10 Notes), not a Narrator appearance
- Static "channel identity" artwork (not tied to any single episode)

**Never use this inside an actual story episode's Visual prompt column.** Episodes stay 100% in-universe (Treta Yuga characters and settings only); the Narrator visual never appears mid-episode.

---

## Visual Lock

Copy this verbatim into any AI image/video prompt that needs to depict the Narrator:

> A warm, approachable Indian man in his late twenties (around 28), with a calm, intelligent, gentle expression — the visual equivalent of a warm, unhurried storyteller's voice. Medium-brown skin tone, South Indian features, short well-groomed black hair (neat, contemporary, not ancient/mythological styling — the Narrator exists outside the story's Treta Yuga setting, in a timeless "today" register), a light, natural short beard or clean-shaven look (pick one and lock it — see note below), warm dark-brown eyes with a soft, attentive gaze directed slightly off-camera or gently toward the viewer. Build: average, unremarkable, non-athletic — he is a storyteller, not a character in the epic. Expression: quiet warmth, the look of someone mid-narration, thoughtful rather than performative — never shown mid-shout, mid-laugh, or with exaggerated expression.

**Wardrobe:** Simple, warm-toned traditional-contemporary Indian clothing — a plain cotton kurta in a muted earth tone (deep maroon, warm ochre, or off-white) with a simple angavastram/shawl optionally draped over one shoulder, evoking a pravachanam (discourse) speaker without being a costume. No jewelry, no elaborate design. Avoid anything that reads as "ancient costume" (that visual register is reserved for the story's actual characters) or "modern Western formalwear" (a suit/blazer would clash with the channel's devotional tone).

**Setting/background (when needed):** A warm, softly lit, uncluttered space suggesting a traditional home or temple courtyard at golden hour — diyas (oil lamps), a soft gold/maroon palette matching the channel's branding (`00_INTRO_OUTRO_TEMPLATES.md`), or a plain warm-gradient backdrop for a clean thumbnail treatment. Never a modern studio/greenscreen look, and never one of the story's actual in-universe locations (that would visually conflate the Narrator with the story itself).

**Lighting/rendering:** Photorealistic, cinematic, warm golden-hour lighting — same realism mandate as the rest of the series (`00_STYLE_GUIDE.md` → "Rendering style — realism"). No illustration, anime, or cartoon style, ever.
